# 直接开始剪辑

1. 用 Blender 5.2.2 LTS 打开 `edit.blend`，先另存工作副本。
2. 时间线已排好 17 镜头、6 章节，共 **7:40、1080p、60fps**。图形引用 `rendered/` 的已渲染素材，调时长不必重渲染场景。
3. 在 **旁白 A / B** 通道删除静音占位，导入真实录音；在 **人物 A / B** 通道替换 PNG 占位并取消隐藏。人物窗口在右上角，字幕在底部。镜头 3 和结尾预留双人并排位置。
4. 按录音调整 **字幕** 通道中的文字与边界；也提供 `subtitles_draft.srt`。**镜头 4 必须补齐全队已确认的技能**，画面只展示计划工作领域，未声称具体技能；工程内保留待补齐备注，该镜头字幕占位默认隐藏。
5. 要延长镜头，添加同编号的 `rendered/shot_XX_hold.png` 并拉长，再将后续条、声音、字幕、人物和标记后移相同长度。每秒 60 帧。转场条长度为 36 帧。
6. 已设置 MPEG-4 / H.264、AAC、1920×1080、60fps；修改输出文件名后，选择 **Render → Render Animation**。

`visuals.blend` 保留可编辑模型、文字、图形和动画。`preview/AI_Game_Player_Pitch_no_voice.mp4` 是完整无旁白、无人物预览。整个文件夹一起移动，保留相对目录结构。

更详细的替换、批量导入、时间调整和许可说明见 `README_使用说明.md`；检查记录在 `qa/`。
